# FanControl

**Ручное управление вентиляторами и мониторинг температур в стиле Windows 11**

Меняйте скорость вентиляторов процессора, корпуса и видеокарты ползунками и следите за температурой CPU и GPU на живых графиках, в одном окне в стиле Fluent.

## Возможности

Программа показывает два блока: **температуры** процессора и видеокарты и **карточки вентиляторов**.

### Температура

- **Графики CPU и GPU**: плавная линия с градиентной заливкой, цвет меняется от зелёного к красному по мере нагрева.
- **Окно времени**: 1, 5, 15 или 30 минут, переключается одной кнопкой.
- **Подсказка под курсором**: наведите мышь на график, чтобы увидеть температуру в конкретный момент и сколько времени назад она была.
- **Мин / средняя / макс** за выбранный период над каждым графиком.
- **Автомасштаб**: шкала подстраивается под данные с шагом 5 °C, размах не меньше 20 °C.

### Вентиляторы

- **Карточка на каждый канал**: текущий процент, обороты в минуту и ползунок.
- **Два режима** на каждый вентилятор: *Система* (скоростью управляет материнская плата или драйвер видеокарты) и *Вручную* (держится заданный вами процент).
- **Плавный переход в ручной режим**: достаточно взяться за ползунок, он стартует с текущей скорости.
- **«Всё системе»**: одна кнопка возвращает все вентиляторы в штатный режим.
- **Статус в заголовке**: сколько вентиляторов сейчас управляется вручную.

### Безопасность

- **Защита от перегрева**: если CPU или GPU достигает 85 °C, ручные каналы со скоростью ниже 60 % автоматически возвращаются системе, а в заголовке на 15 секунд появляется предупреждение. Пороги меняются в начале файла (`SAFE_TEMP`, `SAFE_PCT`), `None` отключает защиту.
- **Штатный режим при выходе**: при закрытии окна, завершении сеанса или закрытии консоли все вентиляторы возвращаются системе. Ваши ручные значения ничего не «застревают» в железе.

### Оформление

- Светлая и тёмная тема, подстраивается под систему.
- Системный акцентный цвет Windows.
- Материал **Mica** на Windows 11 22H2 и новее, на остальных версиях сплошной фон.
- Тёмный заголовок окна в тёмной теме.
- Отдельный значок в панели задач.

## Как это работает

Датчики и управление вентиляторами идут через [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) (пакет `HardwareMonitor` для Python, который работает через `pythonnet`). Для доступа к драйверам нужны права администратора, поэтому при запуске программа сама запрашивает UAC.

**Отдельный поток для железа.** Весь обмен с датчиками происходит в фоновом потоке `Backend`. Интерфейс отправляет ему команды через очередь (`set`, `release`, `release_all`) и раз в секунду получает снимок: температуры, проценты и обороты всех каналов. Поэтому окно никогда не зависает, даже если обращение к датчику затянулось.

**Каналы управления.** Программа ищет датчики типа `Control` у материнской платы и видеокарты NVIDIA и оставляет только те, что перечислены в `WANTED`. По умолчанию это:

| Название в программе | Тип | Датчик |
| --- | --- | --- |
| Кулер CPU | материнская плата | `Fan #1` |
| Корпус | материнская плата | `Fan #2` |
| GPU Fan 1 | видеокарта NVIDIA | `GPU Fan 1` |
| GPU Fan 2 | видеокарта NVIDIA | `GPU Fan 2` |

Обороты берутся из одноимённого датчика `Fan`. Температуры читаются с датчиков `CPU Package` (или `Core Max`) и `GPU Core`.

**Ручной режим.** Значение записывается вызовом `SetSoftware`. Система любит перезаписывать скорость сама, поэтому в ручном режиме программа подтверждает заданный процент каждую секунду. Возврат системе делается вызовом `SetDefault`.

## Установка

### Готовый .exe

Скачайте `FanControl.exe` из раздела [Releases](../../releases) и запустите. Установка не нужна, файл можно положить в любую папку. Программа запросит права администратора.

### Из исходников

Требуется Windows и 64-битный Python 3.11 или 3.12.

```bash
pip install PySide6 HardwareMonitor
python fans_gui.py
```

Права администратора программа запросит сама. Чтобы не появлялось окно консоли, переименуйте файл в `fans_gui.pyw`.

## Консольная версия

Если окно не нужно, есть лёгкая версия `fans_console.py`: те же каналы, те же температуры и графики, нарисованные символами прямо в терминале.

```bash
pip install HardwareMonitor
python fans_console.py
```

Терминал нужно запускать **от имени администратора**.

| Клавиша | Действие |
| --- | --- |
| `↑` `↓` | выбрать вентилятор |
| `←` `→` | скорость ±5 % |
| `[` `]` | скорость ±1 % |
| `A` | вернуть выбранный вентилятор системе |
| `0` | вернуть системе все вентиляторы |
| `Q` | выход |

Клавиши `A` и `Q` работают и в русской раскладке (`Ф` и `Й`). Защиты от перегрева в консольной версии нет, зато при закрытии окна терминала вентиляторы тоже возвращаются системе.

## Настройка каналов

Набор вентиляторов зависит от вашей материнской платы и видеокарты. Если у вас другие имена датчиков, отредактируйте словарь `WANTED` в начале `fans_gui.py` (и `fans_console.py`):

```python
WANTED = {
    ("board", "fan#1"):   "Кулер CPU",
    ("board", "fan#2"):   "Корпус",
    ("gpu",   "gpufan1"): "GPU Fan 1",
    ("gpu",   "gpufan2"): "GPU Fan 2",
}
```

Ключ состоит из типа (`board` или `gpu`) и имени датчика без пробелов в нижнем регистре. Значение это подпись на карточке. Порядок записей определяет порядок карточек.

Остальные параметры лежат там же:

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `SPANS` | 1, 5, 15, 30 мин | варианты окна графика |
| `DEFAULT_SPAN` | `1` (5 мин) | какое окно выбрано при запуске |
| `MIN_SPAN` | `20` | минимальный размах шкалы графика, °C |
| `SAFE_TEMP` | `85` | температура, при которой срабатывает защита |
| `SAFE_PCT` | `60` | ниже этой скорости ручные каналы возвращаются системе |

## Сборка .exe

Положите `fans_gui.py`, `icon.ico` и `build.bat` в одну папку и запустите `build.bat`. Нужен 64-битный Python 3.11 или 3.12 с галочкой «Add to PATH».

Скрипт сам создаст виртуальное окружение `venv`, поставит зависимости и соберёт программу. Результат: `dist\FanControl.exe`. Папки `venv` и `build`, а также файл `.spec` после сборки можно удалить.

Под капотом выполняется команда:

```bash
pyinstaller --noconfirm --clean --onefile --windowed --uac-admin ^
  --name FanControl --icon icon.ico --add-data "icon.ico;." ^
  --collect-all HardwareMonitor --collect-all pythonnet --collect-all clr_loader ^
  --hidden-import clr ^
  fans_gui.py
```

| Ключ | Зачем |
| --- | --- |
| `--onefile` | один .exe-файл |
| `--windowed` | без консольного окна |
| `--uac-admin` | запрос прав администратора при запуске |
| `--icon icon.ico` | значок самого .exe |
| `--add-data "icon.ico;."` | иконка окна и панели задач внутри .exe |
| `--collect-all HardwareMonitor` | библиотеки LibreHardwareMonitor и драйвер |
| `--collect-all pythonnet`, `clr_loader` | мост Python и .NET |
| `--hidden-import clr` | PyInstaller сам этот модуль не находит |

Если антивирус ругается на `--onefile`, замените его на `--onedir`. Программы, которые работают с драйверами железа, нередко вызывают ложные срабатывания.

В `icon.ico` должны быть размеры 16, 32, 48 и 256 px, иначе значок будет размытым.

## Где хранятся данные

Программа ничего не записывает на диск: ни настроек, ни журналов. История температур хранится только в памяти (до 30 минут) и пропадает при закрытии. Ручные значения скоростей тоже не запоминаются: при каждом запуске все вентиляторы под управлением системы.

```
FanControl/
├── fans_gui.py       графический интерфейс
├── fans_console.py   консольная версия
├── build.bat         сборка портативного .exe
├── icon.ico          значок
└── README.md
```

## Важно

Программа напрямую управляет скоростью вентиляторов. Слишком низкие обороты под нагрузкой приводят к перегреву, а при долгой работе без охлаждения железо может пострадать. Защита на 85 °C страхует от забывчивости, но не заменяет внимания: не оставляйте низкие значения при играх, рендере и других тяжёлых задачах.

Если вентилятор не реагирует на ползунок, возможно, канал управляется встроенным контроллером материнской платы или режимом в BIOS. В BIOS включите режим управления вентилятором, который допускает программную регулировку (обычно это режим PWM вместо DC или автоматического профиля).

Если программа пишет «Каналы управления вентиляторами не найдены», проверьте, что она запущена от имени администратора, и сверьте имена датчиков с `WANTED`.

Если закрыть программу аварийно (например, убить процесс в диспетчере задач), вентиляторы могут остаться на последнем заданном значении до перезагрузки или следующего запуска программы и нажатия «Всё системе».
